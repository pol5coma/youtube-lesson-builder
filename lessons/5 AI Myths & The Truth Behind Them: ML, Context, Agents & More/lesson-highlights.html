Five Persistent AI Myths, and What's Actually True

Separate outdated assumptions about hallucination, reasoning traces, compute costs, context windows, and agents from how frontier AI systems actually behave today.

What matters

  • Frontier models still hallucinate, but tool use, refusal calibration, and extended thinking have pushed the rate down to roughly 3% on hard benchmarks.
  • A chain-of-thought trace is the model's narration of its reasoning, not a faithful readout of the computation that produced the answer — a gap researchers call faithfulness.
  • Inference, not training, is now the larger and faster-growing share of AI compute spend, driven mainly by reasoning models emitting far more tokens per query.
  • A million-token context window can find one fact almost perfectly, but accuracy drops sharply when a task requires connecting several facts scattered across that window.
  • An AI agent is a model wrapped in a loop that decides, acts, and observes repeatedly; each step can be reliable on its own while the full chain is not.
  • Reliability compounds multiplicatively across agent steps: a 95%-reliable step repeated 20 times succeeds end to end only about 36% of the time.
  • Refusal calibration — a model saying it cannot verify something instead of guessing — is a trained behavior, not the model being unhelpful.
  • Human-in-the-loop checkpoints and verifier models exist specifically to break the compounding-error chain in long agent runs.

Glossary

Hallucination
A model confidently returning a response that is factually incorrect, without any signal of uncertainty.
Tool use
A model calling an external system — web search, a database, code execution — to ground an answer instead of generating it purely from memorized training data.
Refusal calibration
Training that rewards a model for declining to answer when it cannot verify a claim, instead of rewarding a confident guess.
Extended thinking
Additional inference-time computation a reasoning model spends working through a problem before producing its final answer.
Chain of thought
The visible, step-by-step text a reasoning model generates on its way to an answer.
Faithfulness
The degree to which a model's verbalized reasoning trace causally corresponds to the internal computation that actually produced its answer.
Post hoc rationalization
A reasoning trace that justifies an answer the model's internal computation was already favoring, rather than deriving that answer.
Training
The one-time phase where a model's parameters are tuned across a large dataset, typically over weeks of GPU time.
Inference
Running an already-trained model's fixed weights forward to produce a response to a single query.
Context window
The amount of text a model can take in at once before generating a response, measured in tokens.
Needle in a haystack test
A benchmark that hides one specific fact inside a long context and checks whether the model can retrieve it.
Multi-needle benchmark
A benchmark (such as MRCR) that requires a model to locate and connect several facts scattered across a long context, not just retrieve one.
Agentic loop
The repeating decide-act-observe cycle a language-model-based agent runs through to work toward a goal.
Compounding errors
The failure mode where per-step success probabilities multiply across a chain of actions, causing overall reliability to fall sharply as the chain gets longer.
Human-in-the-loop
A workflow where an agent pauses after a set of steps so a person can review progress before it continues.
Verifier model
A model used to check each step of an agent's work before the agent proceeds to the next step.
