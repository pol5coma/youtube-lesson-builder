Overview

A neural network looks intimidating from the outside, but it is built from one small, repeated unit: the artificial neuron. Each neuron takes in a list of numbers, multiplies them by a set of learned importance values, adds them up, and squashes the result into a signal. Nothing more mysterious happens at the level of one neuron than a dot product, an addition, and a squashing function.

This lesson walks through that computation step by step, using a running example: a neuron that helps predict a house's price from features like square footage and bedroom count. You'll see how raw data becomes a vector, how weights encode which features a neuron cares about, why a bias term matters, and why the final squashing step (the activation function) is what gives neural networks the power to learn anything more complex than a straight line.

By the end, you should be able to take a small set of inputs, weights, and a bias, and compute a neuron's output yourself with a calculator — which is the best way to demystify what training a neural network actually adjusts.

Key takeaways

  • A neuron turns an input vector into a single output signal by computing a weighted sum of the inputs, adding a bias, then passing the result through an activation function.
  • Weights encode how much a specific neuron cares about each input feature; every neuron in a layer sees the same input vector but specializes by learning a different set of weights.
  • The bias shifts a neuron's activation threshold, letting it fire even when the weighted sum of its inputs is small or zero.
  • Activation functions like sigmoid or ReLU introduce nonlinearity. Without them, stacking any number of neurons would still compute nothing more than one overall linear function.
  • A neuron's activation level (its output after the activation function) is a measure of how strongly the pattern that neuron detects is present in the current input.
  • Training a network means repeatedly adjusting every neuron's weights and biases to reduce prediction error; backpropagation is the algorithm that works out how to adjust them, though it isn't covered in depth here.
  • Tools like MLflow don't change what a neuron computes — they log and visualize how weights and biases evolve across training runs so engineers can compare configurations.

The Neuron as a Function: Vector In, Signal Out

A neural network is a collection of neurons, and each neuron is just a small function: it takes a vector of numbers in and produces one output signal.

Key points

  • A neuron's input is always a vector (an ordered list of numbers); its output is always a single number.
  • That single output number is called a signal or activation, and it feeds into the next layer.
  • Understanding one neuron's math is the foundation for understanding the whole network.

Turning Real-World Data Into a Vector

0:40

Before a neuron can process data, real-world features have to be encoded as normalized numbers and arranged into an input vector.

Key points

  • Raw features (square footage, bedrooms, bathrooms, zip code) are normalized to a common numeric scale before use.
  • Normalization prevents a feature with naturally large raw values from dominating the computation just because of its units.
  • The normalized features are arranged in a fixed, consistent order to form the input vector.
  • Every data point (every house) is encoded with the same feature order, so the same vector position always means the same feature.
03

Weights: Encoding Learned Importance

1:25

Each input feature is multiplied by a weight — a learned number representing how important that feature is to this particular neuron — and the products are summed.

Key points

  • Every input feature has a matching weight: a learned number representing that feature's importance to this specific neuron.
  • A large weight means the neuron pays close attention to that feature; a small weight means it mostly ignores it.
  • The weighted sum is computed by multiplying each feature by its weight and adding the results together.
  • The weighted sum is mathematically a dot product between the input vector and the weight vector.

How Neurons in the Same Layer Specialize

2:09

Every neuron in a layer receives the identical input vector, but each has its own independent weights, so different neurons learn to detect different patterns.

Key points

  • All neurons in a layer receive the same input vector; only their weights differ.
  • Different weight sets cause different neurons to respond strongly to different feature combinations.
  • Specialization emerges from training: weights that help reduce prediction error get reinforced.
  • Across many neurons, the layer collectively covers many different useful patterns in the data.
05

Squashing the Weighted Sum: Activation and Bias

2:52

The raw weighted sum can be any number, so a neuron adds a bias and then applies an activation function like sigmoid to squash the result into a bounded, usable range.

Key points

  • A raw weighted sum is unbounded, which makes it hard to interpret or compare across neurons.
  • The sigmoid activation function squashes any input into the range (0, 1).
  • The bias is a single learned number added before activation; it shifts the neuron's activation threshold independent of the inputs.
  • The full neuron computation is sigmoid(weighted_sum + bias).
  • Most modern networks use ReLU instead of sigmoid for computational efficiency, though sigmoid is conceptually simpler.
06

Why Nonlinearity Lets Networks Learn Complex Patterns

3:35

The activation function is what makes a network nonlinear; without it, stacking any number of neurons would collapse into a single linear model.

Key points

  • Stacking layers of pure weighted sums, with no activation function, still only computes one overall linear function.
  • The activation function's nonlinearity is what lets multi-layer networks represent curved, complex relationships.
  • An activation level near 1 (sigmoid) signals the neuron's pattern is strongly present; near 0 signals it's absent.
  • This is why activation functions are sometimes described as deciding 'whether a neuron fires.'
07

From One Neuron to a Network: Stacking, Weights, and Training

4:20

A single neuron can only capture one relationship, but stacking many, fully connected between layers, lets a network learn combinations of patterns; training is the process of tuning every weight and bias.

Key points

  • A single neuron can only capture one relationship; networks gain power by stacking many neurons.
  • In a fully connected network, every neuron connects to every neuron in the next layer, each connection with its own weight.
  • Training means searching for the weight and bias values across the whole network that minimize prediction error.
  • Backpropagation is the algorithm that determines how to adjust every weight and bias to reduce error (a topic beyond this lesson).
  • Tools like MLflow track and visualize how weights and biases evolve during training, without changing the underlying neuron computation.

Glossary

Neuron
The basic unit of a neural network. It takes a vector of numbers as input and produces one output number by computing a weighted sum, adding a bias, and applying an activation function.
Vector
An ordered list of numbers, where each position represents a specific measurable feature of the data being described.
Weight
A learned number attached to one input feature of one neuron, representing how much that feature matters to that neuron's output.
Weighted sum
The result of multiplying each input by its matching weight and adding all the products together; mathematically a dot product of the input vector and the weight vector.
Bias
A single learned number added to a neuron's weighted sum before activation. It shifts the neuron's activation threshold independent of any input feature.
Activation function
A function applied to a neuron's weighted sum (plus bias) that squashes it into a bounded, usable output and introduces nonlinearity into the network.
Sigmoid function
An activation function that compresses any real number into the range between 0 and 1, commonly used to conceptualize a neuron's output as a confidence level.
ReLU
Rectified Linear Unit, an activation function that outputs the input directly if it's positive and 0 otherwise. Used more often than sigmoid in modern networks for its computational efficiency.
Activation level
A neuron's output after its activation function has been applied; a higher activation level means the pattern that neuron detects is more strongly present in the current input.
Nonlinearity
A property of a function whose output isn't a fixed straight-line multiple of its input. Activation functions must be nonlinear for stacking multiple layers of neurons to add any representational power.
Layer
A group of neurons that all receive the same input vector, each computing its own weighted sum, bias, and activation independently.
Backpropagation
The training algorithm that works backward from a network's prediction error to determine how much each weight and bias contributed to that error, so they can be adjusted to reduce it.

Check yourself

Answer first, then open each one.

Why does a neural network need a nonlinear activation function instead of just passing the weighted sum straight to the next layer?

Because a weighted sum is a purely linear operation, and stacking any number of purely linear layers is mathematically equivalent to a single linear layer — you'd gain more tunable numbers but not more expressive power. A nonlinear activation function (sigmoid, ReLU, etc.) breaks that collapse, which is what lets a multi-layer network represent curved, complex relationships between inputs and outputs.

Two neurons in the same layer receive the exact same input vector. Why can they end up detecting completely different patterns?

Because each neuron has its own independent set of weights (and its own bias). Training adjusts each neuron's weights separately based on how much that neuron's output helps reduce the network's overall prediction error, so different neurons drift toward emphasizing different feature combinations even though the input they see never changes.

What does the bias term let a neuron do that the weights alone cannot?

The bias shifts a neuron's activation threshold independent of any input. Without it, a neuron's weighted sum would be forced toward 0 whenever the inputs themselves are small, making it impossible for the neuron to fire in that case. The bias lets a neuron fire even when all its inputs are small (or, with the opposite sign, makes it harder to fire even with sizeable inputs).

If a neuron's weighted sum plus bias comes out very negative, what does its sigmoid output tell you about that input?

Sigmoid squashes very negative values toward 0, so a very negative weighted sum produces an activation close to 0. That means the neuron is effectively 'off' for this input: the specific pattern this neuron has learned to detect is essentially absent from the current data point.

The video says most modern networks use ReLU instead of sigmoid. What's the stated reason, and what is that reason actually about?

Efficiency. Sigmoid requires computing an exponential for every neuron on every forward pass through the network, while ReLU only requires comparing a number against zero. At the scale of modern networks with millions of neurons, that difference in computation adds up, which is why ReLU is preferred in practice even though sigmoid is easier to reason about conceptually.
